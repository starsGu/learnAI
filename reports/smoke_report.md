# 冒烟验证报告

验证环境：Conda `cuda`，PyTorch 2.13.0+cu132，NVIDIA GeForce RTX 5070 12GB。未安装、升级或降级环境中的任何包。

## 已通过

- 13 项单元测试通过。
- 自研 Qwen3 与 Hugging Face 官方微型实现的 logits 和 loss 在 `1e-5` 容差内一致。
- 因果遮罩、标签位移、GQA、权重绑定、固定随机采样和数据哈希切分通过。
- 微型模型可在单批数据上过拟合至初始 loss 的 20% 以下。
- checkpoint 模型、优化器、调度器、随机状态和数据位置可恢复。
- 微型 CUDA 训练完成 1,024 tokens，并从 step 32 恢复至 1,280 tokens；数据位置由 64 精确推进至 80，生成 step 8、16、24、32、40 checkpoint。
- checkpoint 已成功导出为 Hugging Face 格式，导出前后 logits 一致。
- 固定开发提示共 120 条，最终保留提示共 60 条，二者没有重复。

## 完整模型显存探针

- 参数量：596,049,920。
- 输入：batch size 1，序列长度 16，BF16，梯度检查点，fused AdamW。
- 完成：前向、分块交叉熵、反向传播和一次优化器更新。
- 峰值显存：4.50 GiB。

该结果只证明完整模型能在本机完成极短序列单步训练，不能用于估算 2048 长度正式训练的显存或速度。

## 微型生成结果说明

微型冒烟训练只使用约 346 个不同训练 tokens，并累计训练 1,024 tokens。训练 loss 有下降，但生成文本仍以随机、混合语言片段为主，不能据此判断模型已经学会中文。该训练只验证代码链路；语言能力必须在 100M、1B 和 10B 里程碑分别评测。

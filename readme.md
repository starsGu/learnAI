## 目标

能够根据已有文本进行基本的上下文续写，生成语法通顺、内容相关且前后一致的中文文本。

## 模型

框架为 Qwen3-0.6B，所有模型权重随机初始化并从头训练。

- `models/`：存放模型结构、配置和生成逻辑。
- `checkpoints/qwen3-0.6B/`：保存模型权重和训练状态。
- 最终模型采用 Hugging Face 格式，包含 `config.json`、`generation_config.json`、分词器文件和 `.safetensors` 权重。
- 训练 checkpoint 还需保存优化器、学习率调度器、训练步数和随机状态，以支持断点续训。

## 数据集

使用中文预训练数据集。

- `datasets/`：存放数据下载、清洗、去重、分词和加载代码。
- `--data `：指定存放下载的原始数据和处理后的训练数据，默认为d:/datasets/llm。
- 数据划分为训练集、验证集和最终测试集。
- 验证集和测试集不得参与模型训练。

## 测评

每隔固定训练步数保存 checkpoint，并使用相同的验证集和固定续写测试集进行测评。

### 自动测评

- 计算训练集损失和验证集损失。
- 计算验证集困惑度。
- 观察验证集指标是否随训练推进而改善。
- 统计乱码、异常重复、过早结束和无法结束的比例。
- 比较随机初始化模型、不同 checkpoint 和最终模型的结果。

### 人工续写测评

建立固定的上下文续写测试集，覆盖句子补全、段落续写、指代关系、因果关系、格式延续和简单逻辑。

| 维度 | 0分 | 1分 | 2分 |
|---|---|---|---|
| 语法通顺 | 无法阅读 | 局部不通顺 | 基本自然 |
| 上下文相关 | 与上文无关 | 部分相关 | 能自然承接上文 |
| 前后一致 | 明显矛盾 | 有轻微跳跃 | 无明显矛盾 |
| 信息完整 | 中断或重复 | 基本完成 | 完整自然 |
| 基础逻辑 | 明显错误 | 关系含糊 | 因果或推导合理 |

所有 checkpoint 使用相同的提示、生成参数和随机种子。最终确定模型后，再使用一套未参与模型选择的新测试集进行复测。

### 训练

以总条数算
总条数 = 数据条数*epoch
一个batch训练 = 1 (条/num_gpu)
多卡一个batch训练 = batch_size * num_gpu = 4(条)
一个step训练 = 多卡batch_size * grad_accumulate (条),一个step一次更新
steps = 总条数/一个step训练的条数 

以总token数算
总条数 = 数据条数*epoch
一个batch训练 = 2048 (token/num_gpu)
多卡一个batch训练 = batch_size * num_gpu = 4096(token)
一个step训练 = 多卡batch_size * grad_accumulate (条),一个step一次更新
steps = 总条数/一个step训练的条数 

# 模型指令能力训练

## 目标

在预训练模型的基础上训练指令能力，使模型能够：

- 回答基本问题；
- 进行多轮中文对话；
- 遵循简单指令；
- 完成选择题；
- 完成答案较短、评分规则明确的填空题。

## 数据集

使用中文问答、多轮对话、指令遵循、阅读理解、选择题和填空题数据。

划分训练集、验证集和最终测试集，并检查训练题与测试题之间是否存在重复或近似改写。

## 测评

每隔固定训练步数保存 checkpoint，并在相同的指令验证集上测试。

### 客观测评

- 选择题：计算准确率。
- 填空题：计算严格匹配率，并补充关键词或标准化答案得分。
- 指令遵循：统计是否满足指定格式、长度和内容要求。
- 多轮对话：测试模型能否正确理解前三至五轮中的信息、指代和追问。
- 比较指令训练前的预训练模型、不同 checkpoint 和最终模型。

### 人工对话测评

| 维度 | 0分 | 1分 | 2分 |
|---|---|---|---|
| 语法通顺 | 无法阅读 | 局部不通顺 | 基本自然 |
| 问题相关 | 答非所问 | 部分相关 | 正确回应问题 |
| 多轮一致 | 忘记或矛盾 | 部分保持 | 正确延续上下文 |
| 指令遵循 | 未执行指令 | 部分执行 | 完整执行 |
| 信息完整 | 中断或重复 | 基本完成 | 完整自然 |
| 基础逻辑 | 明显错误 | 关系含糊 | 因果或推导合理 |

最终模型使用未参与训练、调参和 checkpoint 选择的新测试集复测。
